# TASK-HUB-011: 再生中の配置のがたつきを無くす

**要件**: REQ-022

## 背景

公開ページで 160 件を1件ずつ進めて計測したところ、次の要素の位置・大きさが出来事ごとに変わっていた（2026-09-22）。

| 要素 | 変化 |
|---|---|
| いま起きたこと（高さ） | PC 9通り（79〜199px）、スマートフォン 37通り。下の画面全体が上下に動く |
| 再生スライダー（幅） | 10通り（826〜925px）。位置・日時の文字幅で伸び縮みする |
| 案件ナビの項目（高さ） | 3通り |
| 案件カード（高さ） | 11通り |

## 受入条件

- いま起きたことは、出来事の内容に依らず同じ構造（見出し・補足・Hub の統制の欄）で描画し、高さを固定する。長い文は行数を制限し、全文は title で読める
- 再生バーの情報欄の幅を固定する
- 案件ナビ・案件カードの進み具合と注意の欄は、中身が無いときも場所を確保する
- 公開前に、ブラウザで全件を1件ずつ進め、上記の要素の位置と大きさが1通りであることを計測する

## 変更許可範囲（allow）

- `src/ui/**`
- `src/styles/**`
- `docs/**`
