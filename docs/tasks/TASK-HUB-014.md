# TASK-HUB-014: デザインレビュー①：ガイド・次の停止へ・いま起きたこと

**要件**: REQ-017, 019, 025 / AC-013

**出どころ**: デザインレビューの指摘（受領物は git 管理対象外）

## 受入条件

- ガイドを4ステップにし、1枚目で「これは再生である」ことと見どころ（Hub が止めた場面）への移動を示す
- 再生バーに「次の停止へ」を置き、現在位置より後の最初の統制ポイントへ移動する。以降に無ければ押せない
- 「いま起きたこと」をヘッダ帯付きのカードにし、統制時は赤帯で「Hub が止めた場面」、通常時は「通常の出来事」と示す
- ヘッダ帯に再生位置と時刻を出し、「Hub の判断」欄から次の停止へ移動できる
- 再生中に配置が動かないこと（REQ-022）を保つ

## 変更許可範囲（allow）

- `src/ui/**`
- `src/app.tsx`
- `src/styles/**`
- `docs/**`

## 変更禁止（deny）
